# Code Smell Prompts

Use these as questions, not verdicts. Context and project policy decide whether a structure is justified.

- Duplicated code
- Long function or module
- Large class or broad responsibility
- Long parameter list
- Divergent change or shotgun surgery
- Feature envy or inappropriate intimacy
- Data clumps and primitive obsession
- Switch statements replacing stable polymorphism
- Parallel inheritance hierarchies
- Lazy class, speculative generality, or middleman
- Temporary fields, message chains, or incomplete library use
- Comments compensating for unclear structure

Prefer the smallest correction that preserves behavior, evidence, safety, persistence, and compatibility constraints.
